🚀 Integration
Laravel Backend Guide
Connecting to Laravel
Step 01
Convert to Blade

Rename .html → .blade.php. Extract shared navbar/footer into layouts/app.blade.php and use @extends + @section.

Step 02
Set API Base URL

Set window.GITAcademy_API_URL in your Blade layout to your Laravel API URL. api.js picks it up automatically.

Step 03
Auth — Laravel Sanctum

php artisan sanctum:install

Use auth.js login/register functions. They post to /api/auth/login and store the Bearer token in localStorage.

Step 04
Replace Static Data

Replace hardcoded HTML course cards with JS calls to coursesApi.list() and renderCourseGrid() from utils.js. Connect payments to Paystack or Stripe.
